# Оброблені дані

Ця папка призначена для зберігання аналітичних таблиць, експортованих із Notebook після очищення, перевірки та трансформації даних.

Наразі Notebook створює робочі таблиці безпосередньо в пам’яті (наприклад, річні підсумки зовнішньої торгівлі, частки імпорту за товарними групами, географічну структуру постачальників та показники за окремими товарними групами). Однак ці таблиці не експортуються в окремі файли CSV або Excel.

Тому на цьому етапі папка не містить наборів оброблених даних. Не додавайте вигадані або відтворені вручну файли.

Якщо надалі виникне потреба в окремих наборах даних, експортуйте відповідні підсумкові таблиці безпосередньо з Notebook і задокументуйте тут їхні назви, поля, одиниці вимірювання та часовий період.
