# Вихідні дані

Ця папка призначена для зберігання оригінального, незміненого файлу з вихідними даними, використаного в аналізі.

**Джерело:** [Державна служба статистики України — Зовнішня торгівля товарами](https://stat.gov.ua/uk/explorer?urn=SSSU%3ADF_EXTERNAL_TRADE_OF_GOODS%28~%29)

Notebook завантажує CSV-файл за посиланням на Google Drive. Завантажте той самий набір вихідних даних і розмістіть його в цій папці, за можливості зберігши оригінальну назву файлу. Не перезаписуйте та не редагуйте вихідний файл вручну.

**Важливо:** сам CSV-файл не включено до цього пакета репозиторію, оскільки його не було надано окремо разом із Notebook. Додавайте його лише після підтвердження, що його вміст відповідає вихідному набору даних, використаному для аналізу.
