# Аналітичні ноутбуки

У цій папці міститься Jupyter Notebook, використаний для завантаження даних, перевірки їхньої якості, підготовки аналітичних таблиць, розвідувального аналізу, розрахунків, побудови графіків та формування висновків.

## Основний Notebook

`01_ukraine_import_analysis.ipynb` — аналіз зовнішньої торгівлі товарами України за 2015–2024 роки.

## Інструменти

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook / Google Colab
